frameline

A small timeline for marking time. Frame-exact, SMPTE timecode with drop-frame, keys on rows, and a clock that stays yours.

Install

npm install frameline

import { Timeline } from "frameline";
import "frameline/style.css";

const timeline = new Timeline(element, { rate: { n: 30000, d: 1001 }, model });
timeline.follow(() => myClock.frame());                // the clock is yours
timeline.on("seek", ({ frame }) => myClock.seek(frame)); // the person scrubs

Why it keeps time

  • Whole frames at a stated rate. Never floating seconds: 29.97 is { n: 30000, d: 1001 } and 00:01:00;02 is exactly frame 1800.
  • The host owns the clock. The playhead follows it once per display frame, so it is never more than one frame behind.
  • Events are only what the person does. Anything you do through the API is silent, so two timelines, or a timeline and a video, cannot echo each other.
  • It proposes, you decide. A drag reports keymove; nothing changes until you answer with setModel.
  • About 7 KB gzipped, no dependencies, plain DOM, restyled with CSS variables.
